# Datasets

```
dataset/
├── original/    authentic images        (put research-dataset files here)
├── forged/      tampered images
├── masks/       ground-truth masks for forged/ (white = tampered)
└── synthetic/   generated by `python -m modules.synthetic` (ready to use)
```

The app and tests never need a downloaded dataset. To evaluate on research data,
copy the files into `original/`, `forged/`, `masks/` and run:

```bash
python -m modules.evaluation --dataset dataset
```

## Sorting the common datasets

| Dataset | original/ | forged/ | masks/ |
|---|---|---|---|
| **CoMoFoD** (small, 512x512) | `*_O.png` | `*_F.png` (and `*_F_JC*`, `*_F_BC*` etc. variants) | `*_B.png` - auto-matched to `*_F.png` |
| **CASIA v2.0** | `Au/*` | `Tp/Tp_S_*` (S = same image = copy-move; `Tp_D_*` are splicing) | `*_gt.png` from the community CASIA2 ground-truth release |
| **DEFACTO** (copy-move split) | the MS-COCO source images | the copy-move image folder | the matching probe masks |

Mask lookup tries `<name>`, `<name>_mask`, `<name>_gt`, `<name>_GT` and the
CoMoFoD rule `001_F` / `001_F_JC3` -> `001_B`. Rename masks to one of these if your copy differs.

Note: CASIA v2.0 mixes splicing and copy-move. This detector targets copy-move,
so evaluate on the copy-move subset for a fair image-level result. Some datasets
mark only the pasted region in the mask; this detector marks both the source and
the copy, so pixel precision will be underestimated on those datasets.
